Overview

Built an end-to-end hiring automation workflow using n8n that eliminates manual resume screening and interview coordination. The system continuously monitors a cloud storage folder for new resumes and processes each candidate through an intelligent evaluation pipeline powered by LLMs.

Workflow Breakdown

  • Trigger: Watches a Google Drive folder for new resume uploads
  • Parsing: Extracts structured candidate data from resumes
  • Evaluation: Matches candidate profile against Job Description
  • Scoring: Uses LLM-based scoring to rank candidates
  • Decision Logic: Compares score with threshold value

Automation Actions

Based on candidate evaluation, the system performs automated actions:

  • Qualified Candidates:
    • Checks interviewer calendar availability
    • Schedules interview slot automatically
    • Sends confirmation emails to candidate and interviewer
  • Rejected Candidates:
    • Sends personalized regret email

Technical Architecture

  • n8n for workflow orchestration and automation
  • LLM integration for semantic resume evaluation and scoring
  • Google Drive API for file monitoring
  • Email APIs for automated communication
  • Calendar API integration for interview scheduling

Key Features

  • Fully automated recruitment pipeline
  • Real-time resume processing
  • LLM-powered candidate scoring
  • Automated interview scheduling
  • End-to-end communication handling

Results & Impact

This workflow significantly reduces hiring turnaround time by automating repetitive tasks such as resume screening and interview coordination. It ensures consistent evaluation of candidates while improving recruiter efficiency and candidate experience.
