Prompt Safety Classification

QLoRA fine-tuned LLM guardrail model that classifies prompts as benign, harmful, or jailbreak, trained end-to-end on a single free-tier T4 GPU.

Published JUL 2026
Category LLM Safety / Fine-Tuning
Status ● Completed

Overview

Built an end-to-end LLM guardrail classifier by fine-tuning Llama-3.2-1B-Instruct with QLoRA (4-bit quantization, LoRA rank 16) using Unsloth and TRL's SFTTrainer, entirely on a single Colab T4 GPU. The task was framed as generative classification in the style of Meta's Llama Guard: given a system prompt defining the taxonomy, the model outputs a single label token - benign, harmful, or jailbreak instead of using a separate classification head.

The model was trained on a stratified, deduplicated sample of a 150k-row labeled prompt dataset and benchmarked against a zero-shot baseline of the same base model with no fine-tuning. The fine-tuned model reached 0.99 F1 across all three classes, while the zero-shot baseline failed to follow the required single-word output format on more than half of its responses.

Technical Architecture

The system was designed around a resource-constrained fine-tuning pipeline optimized for free-tier GPU limits, with an emphasis on rigorous, leakage-checked evaluation rather than a single headline metric.

  • Fine-tuned Llama-3.2-1B-Instruct via QLoRA (4-bit NF4 base weights, LoRA adapters in fp16)
  • Used Unsloth for memory-efficient training and TRL's SFTTrainer with loss masked to the assistant turn only
  • Framed classification generatively (Llama-Guard style) rather than with a classification head
  • Deduplicated training data and ran a near-duplicate check between train and test splits to validate reported metrics
  • Benchmarked against a zero-shot baseline of the un-fine-tuned base model on identical prompts
  • Diagnosed and fixed evaluation pitfalls, including truncated baseline generations and a label-parsing regex bug
  • Published the LoRA adapter with a documented model card to Hugging Face Hub, alongside an interactive Gradio demo

Results & Performance

The fine-tuned model achieved strong, well-generalized classification performance on a held-out test set, with a large margin over the zero-shot baseline.

  • Overall Accuracy: ~94%
  • F1 Score (macro): 0.99
  • Precision: 0.98–1.00 across classes
  • Recall: 0.99–1.00 across classes
  • Zero-shot baseline macro F1: ~0.24, with 55% of responses failing to follow the output format

This project demonstrates practical experience with parameter-efficient fine-tuning (PEFT/QLoRA), resource-constrained training on consumer-tier GPUs, rigorous ML evaluation methodology, and end-to-end deployment of a fine-tuned LLM.
