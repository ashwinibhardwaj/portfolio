Prompt Safety FineTuning

Overview

This project focuses on improving the safety of Large Language Models by fineTuning an instructionTuned model for prompt safety classification. The model predicts whether an incoming prompt belongs to one of three categories: Benign, Harmful, or Jailbreak.

The model was trained on a curated subset of the WildJailbreak dataset using parameterEfficient fineTuning with QLoRA, PEFT, and Unsloth. Training was optimized for limited GPU resources using 4Bit quantization while maintaining strong inference performance.

Technical Architecture

A complete LLM fineTuning pipeline was implemented, covering dataset preprocessing, supervised fineTuning, evaluation, inference, and deployment to Hugging Face Hub.

  • FineTuned an instructionTuned LLM using QLoRA and LoRA adapters
  • Implemented parameterEfficient training using PEFT and Unsloth
  • Used 4Bit quantization for memoryEfficient GPU training
  • Prepared and cleaned the WildJailbreak dataset for supervised learning
  • Built an inference pipeline for prompt safety prediction
  • Merged LoRA adapters into the base model for deployment
  • Published the trained model on Hugging Face Hub
  • Developed a Gradio application for realTime prompt classification

Training Pipeline

The complete workflow consisted of:

  • Dataset preprocessing and label preparation
  • Instruction formatting for supervised fineTuning
  • QLoRABased training with PEFT
  • Evaluation on unseen validation prompts
  • Adapter merging for standalone inference
  • Deployment to Hugging Face Hub
  • Interactive Gradio demo for public usage

Results

The resulting model successfully classifies prompts into three safety categories while requiring only a fraction of the trainable parameters compared to full fineTuning. The project demonstrates practical experience with modern LLM fineTuning techniques, efficient GPU utilization, model deployment, and AI safety workflows.
