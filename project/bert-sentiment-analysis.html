BERT Sentiment Analysis

Fine-tuned Transformer model for binary sentiment classification using Hugging Face Transformers and PyTorch.

Published MAR 2026
Category NLP / Deep Learning
Status ● Completed

Overview

Developed an end-to-end NLP pipeline for sentiment analysis by fine-tuning the pretrained bert-base-uncased model on the IMDb movie review dataset. The project covers the complete machine learning workflow including preprocessing, tokenization, training, evaluation, and inference using Hugging Face Transformers and PyTorch.

The model was trained for binary sentiment classification and achieved strong performance across standard evaluation metrics. Results were visualized using confusion matrices, and the trained model was deployed to Hugging Face Hub for public inference.

Technical Architecture

The system was designed using a modular deep learning pipeline focused on reproducibility and scalability. Hugging Face Trainer API was utilized for efficient fine-tuning while custom evaluation metrics were implemented for performance monitoring.

  • Fine-tuned pretrained BERT model for sentiment classification
  • Implemented tokenization and preprocessing using Hugging Face Datasets
  • Built training and evaluation pipeline with PyTorch + Transformers
  • Integrated accuracy, precision, recall, and F1-score metrics
  • Generated confusion matrix visualization for model evaluation
  • Published trained model to Hugging Face Hub for deployment

Results & Performance

The fine-tuned model achieved strong sentiment classification performance on the IMDb dataset with high generalization capability.

  • Accuracy: 92.2%
  • F1 Score: 0.92
  • Precision: 0.91
  • Recall: 0.93

This project demonstrates practical experience with Transformer architectures, NLP workflows, model evaluation, debugging, and deployment of deep learning models.
