Vocilite

Chrome Extension

AI-powered Chrome extension that explains highlighted text in simple terms and reads it aloud like a personal tutor on any webpage.

Published JUL 2025
Category Browser Extension / AI
Status ● Completed

Overview

Vocilite is an AI-powered Chrome extension designed to improve comprehension and accessibility while browsing. Users can highlight any text on a webpage and instantly receive a simplified explanation along with an audio narration, making it easier to understand complex information.

How It Works

  • Text Selection: User highlights text on any webpage
  • Processing: Extension sends text to backend API
  • LLM Explanation: LLaMA 3 (via Groq) generates simplified explanation
  • Speech Output: Converts explanation into audio using TTS
  • Delivery: Plays output instantly in the browser

Technical Architecture

  • Chrome Extension APIs for frontend interaction
  • Flask backend for request handling
  • LangChain for prompt orchestration and workflow management
  • Groq (LLaMA 3) for fast LLM inference
  • Text-to-Speech integration for audio output

Key Features

  • Instant simplification of complex text
  • Real-time audio narration
  • Works across any website
  • Fast response using Groq-powered inference
  • Improves accessibility and learning efficiency

Results & Impact

Vocilite enhances digital learning by making content more accessible and easier to understand. It is especially useful for students, professionals, and anyone dealing with complex or unfamiliar topics, acting as an always-available AI tutor directly in the browser.
